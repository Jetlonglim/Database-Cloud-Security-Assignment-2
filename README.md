# Database & Cloud Security: AWS Migration & Risk Assessment

A comprehensive cloud architecture and security project focused on the risk assessment of a legacy on-premises infrastructure and its secure migration to a cloud-based environment. 

---

## 🛠️ Technologies & Infrastructure
* **Cloud Platform:** Amazon Web Services (AWS)
* **Core AWS Services:** Relational Database Service (RDS), Application Load Balancer (ALB)
* **On-Premises Environment:** Windows Server 2019
* **Use Case:** Library Management System

---

## ✨ Features
* **Infrastructure Security Audit:** Comprehensive security risk assessment of a legacy Windows Server 2019 instance to identify vulnerabilities.
* **Secure Cloud Migration:** End-to-end migration strategy transitioning the on-premises Library Management System to a managed AWS cloud environment.
* **High Availability & Load Balancing:** Implementation of AWS ALB to securely distribute incoming network traffic across multiple targets.
* **Managed Database Security:** Utilization of AWS RDS to ensure the database layer is scalable, backed up, and securely maintained.

---

## ⚙️ The Process & Implementation Plan
1. **Risk Assessment:** Analyzed the existing on-premises Windows Server 2019 architecture to identify security flaws, single points of failure, and operational risks.
2. **Cloud Architecture Design:** Designed a secure, highly available AWS architecture tailored to the specific needs of the Library Management System.
3. **Team Coordination:** Collaborated with project partners to distribute research, architecture design, and documentation tasks efficiently. 
4. **AWS Deployment Strategy:** Documented the step-by-step implementation of RDS for data storage and ALB for traffic routing and fault tolerance.

---

## 🧠 What I Learned
* **Cloud Migration Strategies:** Gained practical insight into how enterprises transition legacy systems to modern cloud infrastructures without compromising data integrity.
* **Vulnerability Identification:** Improved my ability to assess legacy server environments and propose modern, secure alternatives.
* **AWS Networking & Security:** Learned how to properly configure Application Load Balancers and managed databases to align with cloud security best practices.
